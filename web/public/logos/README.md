# Logos des clients

Déposez ici les fichiers de logo, puis déclarez-les dans `web/lib/logos.ts`.

- Format conseillé : SVG. Sinon PNG sur fond transparent, 128 px minimum.
- Nommage conseillé : le nom du client en minuscules avec des tirets
  (`maison-nova-drinks.svg`).
- Sans déclaration dans `lib/logos.ts`, l'application affiche un monogramme :
  aucune image n'est demandée au serveur, donc aucune erreur 404.
